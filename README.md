# RAIL ![meteor-logo] ![node-logo] ![rpi-logo]

The Rodent Automated and Integrated Learning (RAIL) system is an inexpensive, reliable, and scalable hardware and software system for presenting visual stimuli, and providing automated reinforcements in order to train mice on touchscreen-based complex visually-guided behavioral tasks.

By leveraging the power of web development tools, open source software, and Internet of Things (IoT) hardware, mass behavioral training is easily configured, implemented, and monitored with RAIL.

## 📋 Features
- ✔️ User accounts & permissions
- ✔️ Device calibration & management functions
- ✔️ Flexible experiment paradigm template system
- ✔️ Auditory, visual, & reward stimuli customization
- ✔️ Modular dependency trees for if-then conditionals
- ✔️ Optional multivariate probability distributions
- ✔️ Browser communication system for hardened security environments
- ✔️ Pre-built datasheets for post-session analysis (.csv, .xls, & .xlsx file formats)
- ✔️ Generic drivers for neuroscience hardware, IoT, & more
- ✔️ Dark mode for low-light requirements🌙
